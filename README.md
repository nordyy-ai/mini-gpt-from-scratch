# MiniGPT from Scratch

Educational implementation of a GPT-like language model
using Python and PyTorch.

## Goals

- Understand tokenization and language modeling.
- Implement a decoder-only Transformer.
- Train a small language model from scratch.
- Evaluate text generation quality.

## Tech Stack

- Python
- PyTorch (planned)
- uv
- pytest

## Status

Work in progress: character-level tokenizer.
