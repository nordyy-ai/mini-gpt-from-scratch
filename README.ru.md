# MiniGPT с нуля

Учебная реализация языковой модели типа GPT
на языке Python с использованием PyTorch.

## Цели

- Разобраться в принципах токенизации и языкового моделирования.
- Реализовать архитектуру Transformer (только декодер).
- Обучить небольшую языковую модель с нуля.
- Оценить качество генерации текста.

## Технологический стек

- Python
- PyTorch (в планах)
- uv
- pytest

## Статус

В процессе разработки: токенизатор на уровне отдельных символов (character-level tokenizer).
